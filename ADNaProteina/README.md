# Del ADN a la proteína

Práctica de bioinformática sobre los procesos que permiten
transmitir y expresar la información genética, desde el ADN
hasta la formación de una proteína.

**Autora:** Adriana Peñate Sosa

## Objetivos

- Comprender la replicación del ADN, la transcripción y la traducción.
- Explorar cómo el splicing alternativo genera diversidad proteica.
- Relacionar la secuencia de aminoácidos con la estructura y función
  de las proteínas.
- Aplicar mediante código los procesos estudiados.
